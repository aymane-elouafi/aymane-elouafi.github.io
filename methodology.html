1 Information Gathering

Learn everything about the target before touching it hard: live hosts, open ports, running services and versions, and how the web app works. Most of a box is won here.

Host Discovery & Port Scanning

  • Confirm the host is up (ping / nmap -sn)
  • Fast full TCP port sweep: nmap -p- --min-rate 10000
  • Deep scan the open ports: nmap -sV -sC -p<ports>
  • Scan top UDP ports (SNMP, DNS, TFTP...): nmap -sU --top-ports 100
  • Note every service + exact version for later CVE lookups
notes: Network Enumeration with Nmap

Service Enumeration / Footprinting

  • Enumerate each open service one by one
  • Check for anonymous / guest / null access
  • Grab banners, versions, certificates and config leaks
  • Pull usernames, shares, files and hostnames where possible
notes: Footprinting NFS · Footprinting FTP · Footprinting DNS · Footprinting SMTP · Footprinting IMAP / POP3 · Footprinting SNMP · Footprinting MySQL

Web Recon

  • Fingerprint the tech stack (whatweb, Wappalyzer, response headers)
  • Directory & file brute force (ffuf, feroxbuster, gobuster)
  • Virtual host & subdomain discovery (ffuf -H Host, gobuster vhost)
  • Read source, JS files, robots.txt, sitemap.xml and comments
  • Find login pages, upload forms and parameters to test later

2 Vulnerability Assessment

Turn the enumeration data into a list of things that might be exploitable: known CVEs, web flaws and plain misconfigurations.

Known Vulnerabilities (version → CVE)

  • Map each service version to public CVEs
  • searchsploit <product version>
  • Search Google / Exploit-DB / GitHub for PoCs
  • Prefer stable, well-understood exploits over noisy ones

Web Vulnerabilities

  • Test inputs for SQL injection
  • Test for XSS (reflected / stored / DOM)
  • Test for file inclusion (LFI / RFI) and path traversal
  • Test file upload restrictions and SSRF
  • Check authentication & access control (IDOR, broken auth)

Misconfigurations & Default Credentials

  • Try default / weak creds on every login and service
  • Look for exposed admin panels, debug pages and backups
  • Check for open shares, open relays and world-readable files

3 Exploitation

Get your first foothold. Prepare the exploit, test it safely, and land a shell as some user on the target.

Service / Network Exploitation

  • Run the chosen exploit against the service
  • Understand what the PoC does before firing it
  • Catch the shell (nc / rlwrap) and stabilise it

Web Exploitation

  • Turn a web flaw into code execution (webshell, SSTI, deserialization)
  • Abuse file upload or LFI-to-RCE chains
  • Use found credentials / tokens to reach admin features

Password Attacks

  • Online brute force / spraying (hydra, crackmapexec)
  • Crack captured hashes (hashcat, john)
  • Reuse found passwords across services

4 Post-Exploitation

You have a shell. Enumerate from the inside, hunt for secrets, and escalate to root / SYSTEM.

Local Enumeration

  • Who am I, my groups and my privileges
  • Run LinPEAS / WinPEAS and read the output
  • Check sudo -l, cron jobs, services, SUID/SGID and capabilities
  • List processes, open ports and installed software

Privilege Escalation (Linux / Windows)

  • Exploit misconfigs: sudo rules, SUID binaries, capabilities, writable paths
  • Windows: token privileges, unquoted service paths, AlwaysInstallElevated
  • Kernel exploits as a last resort
notes: Cap - HTB Walkthrough

Looting & Credential Hunting

  • Grab flags and sensitive files
  • Search configs, history, backups and DBs for passwords
  • Dump hashes / tokens for reuse (lateral movement)

5 Lateral Movement

If more hosts are in scope, use what you looted to pivot through the internal network and reach new targets.

Pivoting & Tunneling

  • Map the internal network from the foothold
  • Set up tunnels / proxies (ssh -L/-D, chisel, ligolo)
  • Reach services only exposed internally

Credential Reuse & Pass-the-Hash

  • Spray looted creds across internal hosts (crackmapexec)
  • Pass-the-hash / pass-the-ticket where NTLM/Kerberos allows
  • Repeat the full methodology on each new host

6 Active Directory

A dedicated track for AD environments (big for CPTS & OSCP). Enumerate the domain, abuse misconfigurations, and work toward Domain Admin.

AD Enumeration

  • Enumerate users, groups, computers and shares (enum4linux-ng, ldapsearch, rpcclient)
  • Map the domain with BloodHound (SharpHound / bloodhound-python)
  • Find the attack paths to high-value targets

AD Attacks

  • AS-REP roasting (users without pre-auth)
  • Kerberoasting (crack service account tickets)
  • Abuse ACLs / delegation / GPO misconfigurations

Domain Dominance & Lateral Movement

  • Move with PtH / PtT via WinRM, WMI, SMBexec, PsExec
  • DCSync to dump domain hashes
  • Golden / Silver tickets for persistence
